# lockloop

Freelancer Accountability, Milestone Escrow, and Proof-of-Work Delivery Platform.

## Features
- **Escrow Room & Milestones**: Milestone tracking, escrow status, fund locking, auto-release timers, and approval workflows.
- **Board, List, Calendar & Timeline Views**:
  - **Board View**: Kanban board with drag-and-drop status management.
  - **List View**: Detailed milestone breakdowns with sub-tasks, deliverables, and payment status.
  - **Calendar View**: Day, Week, and Month views with real-time indicators, dynamic earliest-hour active time slots, and Google Meet scheduling.
  - **Timeline View**: Visual sprint roadmap and milestone timeline.
- **Proof-of-Work Media Feed**: Deliverables feed with media previews, status tags, and submission modal dialogs.
- **Resource Share Manager**: Secure client-freelancer document, credentials, and asset exchange with role-based access.

## Getting Started

First, install dependencies:
```bash
npm install
```

Then run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
